## Cómo usarlas

Elegir una guía como base y ajustar el tiempo durante el ensayo. Las versiones en inglés y español cubren los mismos puntos. La versión técnica amplía la explicación de arquitectura, datos, seguridad y pruebas. Se omiten portada, integrantes y reparto de participantes.

Para la demostración, preparar registros ficticios y un traslado abierto. La [VM GCP](../../deployment/gcp/README.md) está disponible directamente en https://34.18.186.116, con HTTPS y sin procesos locales. Para ejecutar el entorno local, seguir la [guía Docker](../../deployment/README.md); ese entorno quedó detenido al finalizar las verificaciones. No proyectar archivos de configuración privada ni credenciales.

El [guion ampliado](Guion_segundo_parcial.md) conserva la secuencia detallada de demostración y preguntas para el ensayo. Las fichas `.txt` describen servicios individuales como consulta complementaria; las cuatro guías anteriores son el material breve para exponer.
