# Comprobación de etapas

Este directorio conserva auditorías, evidencias y acciones de cierre. Los informes describen el estado comprobado en una fecha y unas fuentes concretas; no son una certificación permanente del código ni una aprobación clínica.

Leer primero el README de cada expediente y seguir su orden. Las demás etapas no tienen una auditoría registrada aquí.

Los requisitos autoritativos siguen en [prompts de entrega final](../prompts/entrega-final/00_contexto_y_reglas.md) y el procedimiento en el [Protocolo de comprobación](../prompts/entrega-final/GUIA_EJECUCION_Y_COMPROBACION.md). No sustituir esos requisitos por las listas resumidas de un informe.

Al repetir una auditoría, conservar el resultado anterior y sus intentos. Registrar nuevas fuentes, fecha, pruebas y veredicto en un expediente o revisión identificable. No sobrescribir una evidencia fallida con una aprobada ni sumar casos superpuestos.
