# Paquete macOS x86_64: comprobación local

El 13/11/2026 se reconstruyó `apps/desktop/dist/RedHouse.app` en macOS x86_64 con Python 3.12.6 y PyInstaller 6.22.0, mediante `sh apps/desktop/build.sh`. El código de `apps/desktop` coincide con el commit `4651c94`; el README editorial se actualizó después. La aplicación ocupa aproximadamente 136 MiB en disco. La carpeta `dist` no está versionada y puede sobrescribirse al volver a construir.

El ejecutable `Contents/MacOS/RedHouse` tiene SHA-256 `caeb0141dcf988b707498d24774c47d5c2f164df7cba76d0c401c376a0f6416a`; ese hash identifica únicamente el ejecutable, no todo el bundle. Se compararon los 34 contratos incluidos en `Contents/Resources/redhouse_desktop/contracts` byte a byte con el código fuente. El arranque con `QT_QPA_PLATFORM=offscreen` y `--smoke-report` devolvió `{"ok":true,"window":true,"xsd":"login.xsd","operation":"login"}`; el JSON original se adjunta. El smoke verifica inicio y recursos, sin sesión ni red.

Se abrió el ejecutable empaquetado en ventana nativa y se capturó únicamente su ventana de acceso, con campos vacíos y sin iniciar sesión: `paquete-mac-login.png`. La imagen se inspeccionó visualmente; los controles son legibles y no presentan recorte. Las demás capturas y pruebas funcionales corresponden a ejecución desde entorno virtual, documentada en sus iteraciones. No se ha comprobado la firma para distribución, notarización, instalación ni ejecución en otro equipo. Windows 11 y macOS arm64 no se han probado; el workflow multiplataforma está preparado pero no se ha lanzado para este corte.
