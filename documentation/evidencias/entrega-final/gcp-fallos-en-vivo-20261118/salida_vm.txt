
== Revocar un token
   -> sesión A consulta su perfil: HTTP 200 en 0.08 s
   -> revocar sesión A: HTTP 200 en 0.26 s
   -> sesión A reusa su token: HTTP 401 unauthorized en 0.01 s
   -> sesión A intenta renovarse: HTTP 401 unauthorized en 0.02 s
   -> sesión B (otro dispositivo) sigue: HTTP 200 en 0.06 s

Qué mostrar al profesor:
   * El token revocado da 401 de inmediato y no se puede renovar; las otras sesiones no se afectan.

== Provocar una respuesta inválida
   -> JSON mal formado: HTTP 400 invalid_body en 0.05 s
   -> tipos y valores inválidos: HTTP 422 validation en 0.11 s — Selecciona o confirma una opción válida.
   -> ruta con identificador inválido: HTTP 400 validation en 0.05 s

Qué mostrar al profesor:

   * Las respuestas inválidas de un servicio a otro (HTML, JSON sin sobre, truncado) se cubren con apps/services/tests/test_dependency_timeout_unit.py: terminan en 503 dependency_unavailable.
