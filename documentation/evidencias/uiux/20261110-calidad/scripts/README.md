# Reproducción de esta revisión

Ejecutar desde la raíz del repositorio. Estos scripts no contienen secretos, pero requieren el entorno local ya autorizado. No preparar datos nuevos en GCP ni ejecutar las pruebas de escritura del laboratorio para reproducir capturas.

1. Conservar la copia de presentación anterior en `.local/uiux-quality-20261110/before` y su `before.json`. `render.py` genera fixtures antes/después usando el entorno Python de `apps/web/.venv/bin/python`; `custom-fixtures.py` añade las variantes. El Python global no tiene todas las dependencias Flask del proyecto.
2. Servir `.local/uiux-quality-20261110/preview` en `127.0.0.1:15053`. `browser.cjs` y `extra-browser.cjs` utilizan Playwright instalado previamente en `.local/gcp-public/browser/node_modules` y el Chrome del equipo. Los fixtures prueban composición; no autorizaciones ni operaciones reales.
3. Para Safari, iniciar `safaridriver` en el puerto 15052 y guardar la respuesta de creación de sesión en `.local/uiux-quality-20261110/safari-session.json`. Requiere automatización remota habilitada por el usuario. `safari.py` mide el ancho CSS real y registra el zoom existente; no lo reduce para hacer caber controles.
4. `public-runtime.cjs` espera Flask real en 15054. No cambia su configuración si el acceso privado está bloqueado. Las dependencias y `.local/runtime/web-client.json` pertenecen al entorno privado, no a esta evidencia.
5. Instalar APK de aplicación y androidTest en el AVD existente API 30. `native_profiles.py` toma credenciales de demostración de archivos privados ya existentes; no imprimirlos ni copiarlos a evidencias. Acepta `REDHOUSE_VISUAL_USER`, `REDHOUSE_REPORT` y `REDHOUSE_VISUAL_SIZE`. `BaselineVisualTest` exige copia aislada del APK anterior; no instalarla sobre sesiones del usuario.
6. La captura nativa final utiliza **el área visible** del teléfono en macOS: ventana `Android Emulator - RedHouseApi30:5554`, posición `{100,30}`, tamaño `{360,748}` puntos. La ventana 1 del proceso es la barra de herramientas; la 2 es el teléfono. Antes de ejecutar el arnés, verificar posición/tamaño y que la ventana esté delante, fuera del Dock y sin otras aplicaciones encima. La imagen por ID de ventana omitía capas del renderizador, por eso no se usa como evidencia final de perfiles. Inspeccionar cada captura antes de compartirla. No desactivar `FLAG_SECURE`.
7. `native_scales.py` cambia únicamente tamaño y fuente del AVD temporal y los restaura en `finally`. Permite `REDHOUSE_WIDTHS`, `REDHOUSE_FONTS` y `REDHOUSE_SCALE_REPORT` para repeticiones puntuales. No ejecutar dos arneses sobre el mismo emulador simultáneamente.

Ejecutar navegadores, compilación y capturas nativas por separado en este equipo: una tanda concurrente agotó los tiempos del arnés. Los scripts escriben informes por caso; un proceso terminado no implica que todos los casos hayan pasado. Revisar `status`, `result`, `error` y las imágenes.

`inventory.py` genera un inventario de fuente, no una matriz de autorización validada. `invariants.py` necesita también la línea base de preparación en `/private/tmp/redhouse-uiux-correction/baseline.json`; su comprobación de literales/efectos no sustituye regresión funcional. Los informes finales incluyen anotaciones manuales sobre ejecución real y límites que no deben confundirse con la extracción automática.
