# Inventario y reservas

Mantiene unidades de sangre y ofertas de órganos, su disponibilidad, reservas y ubicación institucional.

Puerto por defecto: `5104`.

Ejecutar desde `apps/services`: `python run.py inventario --config /ruta/privada/inventario.json`.

Swagger: `/docs`. Contratos estáticos y XSD: [contracts](contracts). Guía común: [README](../README.md).
